# 限制与失败模式

| 边界 | 当前行为 | 使用限制 |
| --- | --- | --- |
| Rust 索引 | 内存 HNSW，单个共享互斥状态 | 重启丢失；没有 WAL、在线删除、分片或持久事务 |
| 知识库同步 | 稳定身份、增量复用、单文件替换 | 三份产物不是事务；仅支持单写者，混代需恢复或独立重建 |
| 索引版本 | 装载与查询校验不可变快照身份 | 更新语料须重启重建；指纹不是身份认证 |
| 授权 | 当前分支不提供 Filter/ACL | metadata 字段不等于权限隔离，不用作多租户安全边界 |
| 文档读取 | TXT、Markdown、HTML、PDF 文本层 | 不支持扫描 PDF OCR |
| 重排 | 模型失败可回退规则并记录原因 | 请求 hybrid_rerank 不代表实际运行模型 |
| Agent | 规则分类、rewrite、显式多跳、最小工具调用 | 不等同于自主模型规划；规则覆盖有限 |
| 引用 | 识别模型输出中的本轮证据 ID | 子串识别不证明语义支持，答案与引用均可能错误 |
| 评测 | 检索指标、回归集和逐题 trace | 工程样例不是公开排行榜或生产质量承诺 |
| 性能 | 各报告记录实际计时范围 | 共享机器、单次顺序实验不支持并发吞吐或 SLA 结论 |

历史案例中出现过“答案实体正确，但引用指向无关正文”。因此答案正确、引用 ID 合法、
证据支持结论必须分别判断，不能只用一个准确率掩盖其他失败。案例与指标见
[评测](evaluation.md)。

BM25 的重复建索引评测与复用索引实验、原生检索计时与 HTTP/端到端计时不能直接混比。
SIFT 近邻金标、精确向量排名和文本相关性标注也是不同参照；报告见
[实验导航](README.md#实验报告)。
